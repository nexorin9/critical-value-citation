### 关键不变量

- **幂等键**：事件幂等键 = `MSH-10 + OBX-3 + OBX-14`；回写幂等键 = `message_control_id`。重复帧只处理一次，重复回写不产生第二条记录，既有事实不被覆盖。
- **状态跃迁受控**：主链 `received → judged → card_built → notified → acknowledged → registered → archived`，分支态 `not_critical` / `pending_ack` / `failed` / `writeback_failed` / `superseded` / `transferred_to_human`；非法跃迁被拒绝并记审计，终态不可静默回退。
- **审计只追加**：审计流水由**库级触发器**锁成只追加（改、删都被拒），且只落标本号 / 项目码 / 时间 / 科室 / 角色；写进患者标识的说明文字**被拒写**，不是脱敏。
- **审计链可证明未被改动**：每条审计行盖「本条内容哈希 + 上一条的链哈希」，逐条重算即可判定链是否被动过；**触发器只追加**与**链哈希可验证**是两件事，后者不依赖前者是否还在 —— 触发器被摘掉，链哈希照样照得出改动，并指出第一个断链位置。
- **重推不改变事实**：到期重推只**追加**一条推送记录，首次推送时刻不被覆盖；「今天推送了多少条」按去重事件数算，重推不灌大；重试耗尽落「处理失败」并告警，事件留在台账里等人接手。
- **推送失败不丢事件、重复推送不刷屏**：重试耗尽 → 死信（原卡内容 + 最后一次错误）+ 事件落「处理失败」等人接手 + 本机队列留档，**事件绝不静默丢弃**；同一事件同一轮次只推一次（抑制键 = 事件 ID + 投递状态 + 尝试轮次），**首次推送与到期重推各占一把锁、互不抑制**；已被人工确认的事件不会被自动路径改回失败态。
- **失败不静默改数据**：单位未知、依据缺失、召回为空、版本空档、幂等冲突一律转人工或落明确失败态，绝不写一个「看起来对」的结论；回写失败不丢已确认回执。
- **一次处置只引一套材料版本**：同一张卡里不得同时出现阈值表的新旧两版，与院内声明的版本绑定不符也不出卡（报 `version_mismatch`）；版本号缺失或两份材料各自独立编号时只标「需人工核对」，不误拦合法组合。
- **出处不可无**：每条引用同时带 `source_sha256`、段落序号、章节路径、可读行号与文件版本；出处不全的引用不计入出处覆盖率。
- **人工确认不可绕过**：判定与检索的产出只是建议；未经值班人确认的事件，出站回写调用次数恒为 0。
- **患者可识别信息不落库**：患者标识只透传到事件标识层用于去重，姓名、身份证、住院号既不落库也不进卡片与推送载荷；审计只落标本号、项目码、时间、科室、角色。
- **判定可复算、但回放只读**：判定链随事件落库，回放按事件 ID 重跑判定并与落库记录逐字段比对；回放**不写台账、不改状态、不重推处置卡**。判定记录同样不落患者可识别明细（连不透明的 `patient_ref` 都不写）。
- **并发与重启安全**：SQLite 开 WAL 与忙等待，幂等键列加唯一约束；进程重启后按状态续跑，不重复推送、不重复回写。
- **入站凭据不将就**：共享令牌用常量时间比较；服务端没配令牌位就一律拒绝，不给默认口令；未授权请求只留审计（来源地址与路径），审计里不出现令牌明文。
- **入站通道不承载患者信息**：HTTP 推送载荷里出现患者标识字段当场拒绝 —— 这条通道只传结果，不传人。
- **对账只读、差异不自动抹平**：对账只读两边、只出差异清单，**不改任何本地状态、不发写请求、不写审计**；要动状态必须显式 `--resolve` 并写明处理人，每一次处理留审计。**查不到 ≠ 没有**：对端整体不可达时直接报错，不出「远端没有」的假清单；单条查不到的条目不判差异，摘要写明「未判定」。
