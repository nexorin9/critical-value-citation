## 2. 只写了一半事实的条款：标字段缺失，不编造


`第十条` 在改版里只写了「上报时限：次日 08:00 前」，没写通知对象与记录去向 ——
处置卡上这两项标缺项并写明原因，**不拿别的条款的取值顶替**。

## 4. 制度改版影响面：按稳定标识逐条对齐

```bash

  --old samples/policy/示例危急值报告制度.docx \
  --new samples/policy/示例危急值报告制度_v2.docx \
  --csv reports/policy_version_diff.csv
```

```text

  · [事实要素变化] 第七条 · 通知对象：检验科值班技师与检验科组长 → 检验科值班技师、检验科组长；上报时限：10 分钟内 → 15 分钟内（处置动作变了，须复核）

```

```text
  · 718-7 → 阈值表 示例 v1.0 + 制度 示例 v1.0（检验科 2026-01 确认）
  · 6690-2 → 阈值表 示例 v1.0 + 制度 示例 v1.0（检验科 2026-01 确认）
```

版本**的处置卡由版本闸门拒绝出卡（`version_mismatch`）。
