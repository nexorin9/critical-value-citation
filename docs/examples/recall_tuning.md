## 已知短板与后续

- 命中率在本评测集上**分辨力有限**：3 个不同档位（最高 100.0%）。阈值与权重在合格区间内的微调多数不改变「期望条目是否落进前 N」，因此推荐规则用「闸门截断更少 / 结构化权重更大」作为平手裁决键，而不是宣称某个点明显更好。
- 指标最优的点（阈值 0.00 · 结构化权重 1.00，Top-5 命中率 100.0%）把两路权重推到边界、把阈值压到 0：它买到了「结构化精确命中的制度条款排到 BM25 高分语料行前面」，但代价是**综合分硬闸门失效**（召回永远不为空，「没依据就说没依据、转人工」走不到），且只被词法路命中的依据综合分恒为 0。它已按规则排除，但结论写在这里，不藏。
- 负例噪声列（材料里没有该项目的查询召回了多少条）是**唯一的噪声旁证**：三个指标只奖励「找到」不惩罚「多召回」，只看命中率会把阈值一路压到 0。
- 推荐参数下拖后腿的查询族：**policy_multi_expect**（Top-5 命中率 50.0%，期望条目 16 条）—— 这一族一条查询要**多处依据**（如通知对象与上报时限分属不同条款），两处要同时落进前 N；而 BM25 得分更高的条款语料行会把精确命中的制度条款挤出前 N。差异归因留给后续的「双路召回差异归因」任务。

---

口径说明：命中率 = 命中条目数 / 期望条目数（负例不进分母）；Top-N 命中率只数落在前 N 名的期望条目；出处覆盖率只对**带出处的引用**计分；负例噪声 = 材料里根本没有该项目的查询召回了多少条（三个指标只奖励「找到」，不惩罚「多召回」，这一列是唯一的噪声旁证）。扫描跑的是线上同一条召回主路径（两路候选 → 融合 → 综合分硬闸门 → 规则重排 → 截断），候选只取一次、逐网格点重算打分，因此结果与线上逐位一致、可复算。
